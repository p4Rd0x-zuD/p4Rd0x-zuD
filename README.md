**Tecnólogo en Redes de Datos** (SENA, 2026) · Infraestructura y soporte TI · Automatización con IA

Trabajo en redes e infraestructura —enlaces inalámbricos de hasta **24 km**, servidores Linux y servicios en la nube— y automatizo procesos con IA.

**Ahora:** Soporte TI / Técnico de Redes Junior · 9 meses.

### 🧰 Capacidades

- **Redes:** VLAN · LAN/WAN · TCP/IP · enlaces inalámbricos punto a punto (24 km) · alta disponibilidad
- **Servidores:** Linux y Red Hat · Docker · VMware / VirtualBox
- **Cloud:** servidor propio con hardening, claves SSH y firewall
- **IA y automatización:** n8n · agentes LLM · APIs · webhooks · Python · PostgreSQL · Git
- **Soporte:** cableado estructurado · impresoras · instalación Linux/Windows

### 🗂️ Proyectos

- **Bots de WhatsApp** — agentes que asesoran, toman pedidos, agendan y consultan la BD `n8n · LLM · APIs`
- **Dashboards de cierre de mes** — de un Excel imposible a gráficas y filtros
- **Automatización Shodan** — reconocimiento diario a las 7:00 AM
- **daily-log** — TILs y notas: [repo](https://github.com/p4Rd0x-zuD/daily-log)
